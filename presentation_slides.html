React Native Core Components Applied

How each component was selected and used to solve the problem

📦View

Layout & Container

Equivalent to <div>. Used Flexbox (flexDirection: 'row') to align photo and text side by side.

🔤Text

Typography Display

Renders headers, student full names (fontWeight: '700'), year levels, and button titles.

🖼️Image

Remote Photos

Renders student avatars. Must have explicit width: 50, height: 50, and rounded corners.

📜ScrollView

Scrollable Card List

Wraps all student cards, enabling vertical touch scrolling beyond screen boundaries with stable keys.

🔍TextInput

Search Filtering

Controlled input bound via value and onChangeText for real-time case-insensitive search.

👆Pressable

Touch Interaction

Interactive advising button with a dynamic style function ({ pressed }) => [...] for tactile feedback.

Component Structure Architecture

Separation of concerns: Stateful Container vs. Presentational Component

StudentDirectory.js Parent / Container
  • • Holds students state (5 student objects).
  • • Holds searchQuery state for TextInput.
  • • Implements filteredStudents via .filter().
  • • Renders cards inside <ScrollView> with key={student.id}.
  • • Defines handleToggleFlag(id) updating flagged status immutably.
StudentCard.js Child / Presentational
  • • Receives: id, name, year, photoUrl, flagged, onToggleFlag.
  • • Uses Flexbox row layout (View).
  • • Renders explicit avatar dimensions (Image).
  • • Displays student name & year level (Text).
  • • Interactive Flag Button (Pressable) executing onToggleFlag(id).

Requirement 6: Uncontrolled Input Experiment

Comparing Controlled vs. Uncontrolled TextInput behavior

✅ Controlled (With value & onChangeText)
<TextInput
  value={searchQuery}
  onChangeText={setSearchQuery}
/>

Every keystroke calls setSearchQuery, updating state and triggering a re-render. The list filters immediately in real-time.

❌ Uncontrolled (Without value & onChangeText)
<TextInput
  placeholder="Search..."
/>

Characters appear inside the input via native buffer, but React state is never updated. The component does not re-render and the list remains unfiltered.

Common Errors & Submission Verification

Key problem-solving insight and submission readiness

⚠️ Common Problem: Remote Image Missing

In HTML web, images have intrinsic dimensions from downloaded files. In React Native, remote images (uri) do not calculate dimensions automatically. If width and height are omitted, the image defaults to 0x0 (invisible).

Resolution: Explicitly specify width: 50, height: 50, borderRadius: 25 in StyleSheet.create.
